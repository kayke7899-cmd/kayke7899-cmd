## ☕ Projetos em Java

### 🧪 [Sistema de Gestão do Laboratório de Enfermagem](https://github.com/kayke7899-cmd/Sistema-de-laboratorio-)

Projeto acadêmico **em grupo (5 integrantes)**, no qual atuei no desenvolvimento e na documentação. É uma aplicação de console para gerenciar um laboratório de enfermagem: agendamento de aulas práticas, solicitação de kits de insumos, controle de estoque e checklists de conferência.

- **Perfis de usuário** com herança e aprovação de cadastro: Professor, Aluno, Equipe de Laboratório e Coordenação
- **Regras de negócio:** antecedência mínima de 7 dias, conflito de horários, capacidade da sala, alerta de estoque mínimo e manutenção de equipamentos
- **Arquitetura em camadas** (`model`, `repository`, `service`) com enums, encapsulamento e validação de entrada
- **Conceitos aplicados:** POO, coleções, `java.time` e modelagem UML

`Java` `POO` `Arquitetura em camadas` `UML` `Trabalho em equipe`

### 📚 [Biblioteca](https://github.com/kayke7899-cmd/Biblioteca)

Aplicação de console para **cadastro e controle de estoque de livros**, com foco na consolidação dos pilares da Programação Orientada a Objetos.

- **Encapsulamento** dos atributos da classe `Livro`
- **Sobrecarga de construtores:** criação com dados básicos ou com preço e quantidade inicial
- **Sobrecarga de métodos:** reposição de estoque com ou sem registro do fornecedor
- Entrada de dados com `Scanner` e execução via terminal ou VS Code (JDK 25+)

`Java` `POO` `Encapsulamento` `Sobrecarga`

### 👨‍💼 [Funcionários](https://github.com/kayke7899-cmd/Funcion-rios)

Aplicação de console para **cadastro de funcionários e aplicação de aumentos salariais**, por percentual ou por valor fixo com registro do motivo.

- **Encapsulamento** dos atributos da classe `Funcionarios`
- **Sobrecarga de construtores:** funcionário com ou sem salário inicial
- **Sobrecarga de métodos:** `aumentarSalario` por percentual ou por valor e motivo
- Entrada de dados com `Scanner` e execução via terminal ou VS Code (JDK 25+)

`Java` `POO` `Encapsulamento` `Sobrecarga`
